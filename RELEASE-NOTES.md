# Coneic Player 0.6.0 for Windows

Download **Coneic-Setup-0.6.0-x64.exe**, or use **coneic-0.6.0-win-x64.zip** with BlueCloud Launcher.

- Playback positions are saved while playing and when paused, including shorter videos. New profiles resume automatically; the playback menu offers Always resume, Ask, or Start from the beginning.
- Audio-track/output selection and playback speed are directly available in the glass controls.
- Space, Left/Right, F and Esc work from the floating controls. Text fields and sliders retain their normal keyboard behavior. Shortcut help is available in More playback options.
- Windows default-player registration and custom icons cover 134 formats. The VLC 3.0.24 engine and all 360 media plugins are retained.

Validated with native UI, glass playback controls, isolated abrupt-exit/resume, engine-preservation and file-association checks. Windows x64 preview; unsigned until a publisher certificate is connected. Source, release metadata and SHA-256 checksums accompany the release.
